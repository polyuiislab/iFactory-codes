# CPU-inspired Manufacturing Systems

This repository contains the research implementations of CPU-inspired approaches for customized production, developed at IIS Lab in PolyU.

The research explores how modern CPU scheduling and execution principles can be adapted to manufacturing systems to improve demand–resource synchronization under uncertainties.

## Repository Structure

### CPUiS1
Source code for our first study, *From Computer CPU to Factory CPU: A Synchronization Framework for Customized Production*.

This study introduces a CPU-inspired synchronization framework for customized production.

### CPUGS
Source code for our subsequent study, *CPU-inspired Granularity-based Synchronization Framework for Multi-stage Customized Production*.

This study develops a granularity-based synchronization framework incorporating CPU-inspired synchronization mechanisms to coordinate production demands and manufacturing resources under pervasive uncertainties.

### iFactory Operating System
The implementation and demonstration of iFactory OS, a software platform developed to integrate CPU-inspired synchronization mechanisms with manufacturing operations.

The demonstration video and Windows installation package are available in the [CPUGS Release](https://github.com/polyuiislab/iFactory-codes/releases/tag/CPUGS).
